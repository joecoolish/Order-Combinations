# Order-Combinations

A small GitHub Pages-ready web app that simulates short-lot draws.

## What it does

- Accepts:
  - total participants (Y)
  - total short lots (X)
  - total simulations
- Runs Monte Carlo simulations and shows the probability of receiving a short lot by draw position.
- Compares observed results with the theoretical probability `X / Y`.

## Run locally

Open `index.html` in a browser.
